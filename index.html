LZTracker

The repository contains a built frontend which is published to GitHub Pages. To view the live site, open:

https://lilianzghibarta-collab.github.io/lztracker/

If you are developing locally, run the frontend dev server with:

npm install
npm run dev

Note: this file no longer loads /src/main.jsx directly to avoid serving source files on GitHub Pages. If you want the Pages site to serve the built app, ensure the GitHub Pages deployment uses the Actions artifact (it already does) and wait for the workflow to finish. If you prefer, you can also delete this file from the repository.
